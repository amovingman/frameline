# Change notes

## Unreleased — experimental local build

- Added ten [self-hosted verification-job capabilities](ASSET_VERIFICATION_JOBS.md), including exact-input deduplication, cancellation/run-guarded retry, private fenced leases, monotonic progress, restart recovery, complete stored-content SHA-256 verification, and scoped metrics/CLI access. Encrypted asset schema 4 preserves existing uploads and lifecycle evidence. No verification job changes media or editor state.
- Added ten [desktop lifecycle features](DESKTOP_ASSET_LIFECYCLE.md): owner project selection, verified report paging, loaded-asset filters, details, reviewed hold editing/release, retention editing, blocked cleanup-plan review, reviewed JSON exports, and durable account-scoped retry recovery. Credentials and retry keys stay in the main process. Deletion remains unavailable.
- Added five self-hosted [asset lifecycle features](ASSET_LIFECYCLE.md): durable owner holds, guarded hold release, retention/archive clocks, paged owner reports, and reviewed cleanup plans through the HTTPS asset API and stdin-only CLI. Encrypted asset schema 3 migrates earlier indexes conservatively. Plans remain blocked until canonical retained references are proven; no bytes are deleted.
- Added twenty [Studio storage features](STUDIO_STORAGE.md#delivered-feature-checklist): private folder registration and reconnection, bounded asset requests, streamed verification/cancellation, restart and interrupted-check recovery, filtered results, and reviewed path-free proposal export. Relink proposals remain non-executable; real studio mount support and editor relinking are not enabled.
- Added read-only FCPXML scan history, review-copy verification, Resolve snapshot review, and local collaboration/media foundations.
- Added first-run setup, cancellable scans, a reviewed path-free diagnostics export, local scan metrics, and a local review-comment store for verified immutable anchors.
- Added release policy checks, CI checks, and recovery policy tests. These do not create signed installers or enable automatic updates.

- Added service-scoped historical shared-base receipts with full ancestry verification, immutable proof snapshots, explicit retry/repair, and separate row/detail labels. Local metadata migrates to schema 5 while preserving legacy bases without treating them as service evidence.
- Added [read-only service sequence comparison](SERVICE_THREE_WAY_COMPARISON.md) between a verified shared base, current source-bound FCPXML scan, and explicitly fetched incoming history. It classifies sequence name, rational frame duration, and frame count without network access or source/history/base writes; clip/media comparison and apply remain unavailable.
- Added [Resolve service history preview](SERVICE_RESOLVE_PREVIEW.md) with independent branch mapping, complete observation transfer, and scoped base/incoming provenance. Saved-head or fresh accepted-capture sources feed the existing API-ID field/conflict review; service reviews cannot authorize the rename drill or claim current live-editor/cross-device identity.
- Added [self-hosted Resolve revision comments](REVIEW_COMMENTS.md) on explicitly fetched immutable observations, with exact clip/range anchors, authenticated role checks, one-way author/owner resolution, scoped idempotent creation, and signed pagination. Combined encrypted state migrates to schema 3 without backfilling comments. Desktop drafts carry an opaque expected-scope guard; FCPXML anchors, cross-revision remapping, and editor writes remain unsupported. All 872 full-suite and 485 security tests passed without skips; [real HTTPS browser/native checks](phase-0/revision-comments-live-observation.json) verified owner posting/resolution, viewer restrictions, plain-text rendering, stale drafts, and session/cache/thread recovery after native app restart.
- Added an opt-in [Rename and verify experiment](phase-0/SAFE_PULL_PREFLIGHT.md#opt-in-desktop-rename-experiments) beside the forced-rollback test for one reviewed clip name on a named disposable project. Version-3 desktop commands retain bound results through Fusion file output, establish a readback replay barrier before editor access, and require explicit host verification before acknowledgment. [Native verification](phase-0/desktop-retained-result-live-observation.json) completed legacy recovery, a normal rename, and an independently reviewed reverse rename acknowledged after an app restart; all saved validated outcome revisions despite lost Console output. All 820 full-suite and 433 security tests passed without skips. Legacy Console audits remain readable. Normal Apply, service-derived mutation, and power-loss guarantees remain unavailable.

- Added self-hosted [branch protection and approval requests](COLLABORATION_FOUNDATIONS.md#branch-approvals-on-a-self-hosted-service), with owner policy-version checks, independent reviewers, seven-day expiry, current-access checks, and exact-head publication gates in the actual queued push path. Combined encrypted schema 4 preserves prior comments/activity and commits applied receipts and audit atomically. History has a service-branch review panel independent of the local editor selection. All 963 full-suite and 576 security tests passed without skips; [native/browser HTTPS checks](phase-0/branch-approvals-live-observation.json) verified the protected queued publication flow and viewer restrictions.

- Added self-hosted [read-only revision links](COLLABORATION_FOUNDATIONS.md#read-only-sharing) with owner copy/revoke controls, bounded expiration, an explicit-open recipient viewer, immutable pinning, current issuer-access checks, strict same-origin/TLS handling, and capability-free renderer state. Combined encrypted schema 5 preserves existing comments and branch approvals while adding scoped creation receipts, capability hashes, revocations, and matching activity. Clipboard failures report confirmed cleanup or a required manual revoke. [Native/browser checks](phase-0/share-links-live-observation.json) verified copy, immutable pinning, revocation denial, and viewer restrictions; the full 1,057-test suite, 670 security checks, packaging, and 75 final focused checks passed.

- Prevented activation from recreating windows during shutdown and deferred the final quit until the native quit event unwinds. A normal signed-out app exited with code 0 after one Quit request.

- Added account-wide service updates independent of local editor selection, with explicit read receipts and All/Unread filtering. Per-project email defaults off and can use immediate delivery or a daily UTC digest. Optional self-hosted implicit-TLS SMTP submission runs through a durable leased worker, rechecks consent and access before DATA, and supports project-specific turn-off links and an account-wide stop. Combined encrypted schema 6 preserves earlier state and stores hashed consent capabilities and bounded retry receipts. Loopback HTTPS/process-restart and TLS mail tests cover exact preference retry, persisted read state, background delivery, redacted access-loss notices, and consent-epoch isolation; no real provider or external email was used. [Native/browser verification](phase-0/notifications-live-observation.json) confirmed app-closed delivery, preference/read recovery, one injected-clock digest, explicit unsubscribe, and generic access-loss controls. The milestone passed 1,176 full-suite and 789 security tests plus 50 final controller/renderer checks after correcting the unchecked unread label; package validation passed.

- Added [durable team templates](COLLABORATION_FOUNDATIONS.md#team-templates) with team-owner management, member reads, version checks, exact preview binding, and atomic creation of an empty service project with branches, access, and initial media policy. Combined encrypted schema 7 preserves prior domains. Existing asset policies remain authoritative after owner edits; creation retries cannot reset them. A private account-scoped desktop journal retains pending save/create identity across restart, with explicit retry and guarded local dismissal. No editor file or media transfer is created by this workflow. [Native/browser evidence](phase-0/team-templates-live-observation.json) verified lost-acknowledgment recovery after restart and a later template edit, with one original project and preserved branches/classes. All 1,270 full-suite and 883 security tests passed; packaging and 36 final copy-focused checks passed.

Compatibility remains limited to the experimental boundary in `phase-0/SUPPORT_MATRIX.md`. No production release date or stable channel has been declared.
